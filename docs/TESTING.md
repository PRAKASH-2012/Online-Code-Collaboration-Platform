# CodeSync AI - Verification & Testing Guide

## 1. Automated Verification
- Run `npm run seed` to seed database with demo users (`prakash_demo`, `arun_demo`, `kumar_demo`, `meena_demo`).
- Run `npm run dev` to launch server and frontend simultaneously.

## 2. End-to-End Test Workflow
1. Navigate to `http://localhost:5173`.
2. Click **⚡ Quick Demo Login** to authenticate instantly as Prakash Demo.
3. Open **AI Student Portal** project workspace.
4. Test Monaco editor typing, code execution (Ctrl+Enter), AI copilot prompt, and Voice Huddle.
