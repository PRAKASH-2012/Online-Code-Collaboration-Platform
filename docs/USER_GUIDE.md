# CodeSync AI - Platform User Guide

## User Manual & Keybindings

### Global Keyboard Shortcuts
- `Ctrl + S`: Save active file & record version history snapshot
- `Ctrl + Enter`: Run active program in isolated sandbox
- `Ctrl + K` or `Ctrl + Shift + P`: Open Command Palette
- `Ctrl + B`: Toggle IDE sidebar drawer

### Interactive Features
1. **Real-time Follow Mode**: Click "Follow Collaborator" in the Git/Collaborators panel to automatically mirror their active file tabs and cursor positions.
2. **Audio Huddle**: Click "Voice Huddle" in the top toolbar to enter instant team voice channel.
3. **Time-Travel Replay**: Click the History icon in the top toolbar to scrub through file evolution over time.
4. **Code Heatmap**: Click the Flame icon in the top toolbar to view line edit frequency decorations in Monaco Editor.
